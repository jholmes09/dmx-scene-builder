DMX Scene Builder
Start here

Connect

  1. Power the float. Wait about 30 s for the E-Box to start.
  2. Put the iPad on the same network as the E-Box.
  3. Open DMX Scene Builder.
  4. Pick the float at the top.
  5. Tap any light control. The app goes live by itself.
First time on a float with no box IP yet: Patch tab > Find > pick the box. Box IPs don't change, so this is once per float.
Turn the power off before plugging or unplugging lights.
Always on screen

Tab 3

Save

Stores the look inside the lights so the float runs with no iPad.

  1. Switch to Mode 7: needed once per float.
  2. Go to Look: set the look.
  3. Save look: writes it into the lights (about 5 s).
  4. Play saved look: the app lets go and the box restarts (about 10 s). The lights should come up in the saved look. This is the check.
ButtonWhat it does
Play saved lookBox runs on its own. The app can't control it, and Go live says so.
Back to app controlBox follows the app again (restarts, about 10 s).
Before the parade, leave every float on Play saved look.
Floats on show control

Parade tab

Shown instead of Save when Float settings says Live DMX input.

  1. Pick the mode show control wants.
  2. Auto-address, then Send addresses to fixtures.
  3. Check with Identify or the Address finder.
  4. Give the programmer the Patch sheet.
  5. Press Released.

Troubleshooting

ProblemTry
Box not answeringBox power on? Network cable in? iPad on the right network?
Live but lights don't changeNet · Sub · Uni match the box? Box on Play saved look? Press Back to app control.
Go live says the box is playing its saved lookSave tab > Back to app control.
"The real lights don't match the app"Press Send addresses to fixtures, then Scan again.
A light runs a demo, or sticks on its saved lookScan, fix any mismatch it reports, then save the look into the lights again (Save tab).
Scan finds fewer lights than expectedCheck the connectors on that cable run. Only the last light on each run should have its terminator on (⋯ on a light).
Find shows nothingSame network? Box finished starting up? Try again after 30 s.
Two lights do the same thingThey share an address. Patch > Auto-address > Send addresses to fixtures.
A look does nothingThe look was saved for lights no longer in the patch. Set it again and Save look.
Float changed on another deviceSomeone else edited it. The app reloads it.
Only for a replacement box

E-Box settings

  • Personality > DMX Input = Ethernet
  • Personality > Ethernet mode = Artnet
  • E-box mode = Pass-Thr
  • Power cycle the box after any change.
