Field guide

DMX Scene Builder. Print this page, or keep it open on the iPad.
Before you leave

What to bring

  • The Mac, plus its charger
  • The USB-C to Ethernet adapter, always the same one. macOS remembers the IP address for each adapter, so swapping adapters means setting the IP again.
  • The iPad
  • A travel router
  • A normal network (Ethernet) patch cable, plus a spare
  • A small screwdriver, in case you need the box's menu under its cover

Plug the patch cable from the Mac's Ethernet adapter (or the travel router) straight into the E-Box's network port.

On some E-Box versions the display and buttons sit under the top cover.

Always disconnect mains power before connecting or disconnecting LED modules.
Do this tonight, before the trip

One-time Mac setup

  1. Open System Settings > Network > the USB Ethernet adapter > Details > TCP/IP.
  2. Set Configure IPv4 to Manually.
  3. IP address 2.0.0.10, Subnet mask 255.0.0.0, Router left blank.
  4. Double-click DMX Scene Builder.command in the dmx-scene-builder folder.
  5. The first time, macOS may ask two questions: whether to allow Terminal on the Local Network, and whether to accept incoming connections. Say Allow to both. (You can check this later at System Settings > Privacy & Security > Local Network > Terminal, make sure it's on.)
  6. Test it: on the Mac, open http://localhost:8080 in a browser. You should see DMX Scene Builder.

Also install the free Robe Toolkit (from robe.cz) as a backup addressing tool, in case the app can't talk to a fixture directly.

Quit Robe Toolkit, Luminair, xLights, and any other lighting app before running DMX Scene Builder. Two apps trying to use the same network port (the Art-Net port) will fight each other, and neither will work right.
On site

Connecting at the shop

Recommended setup:

  • iPad joins the travel router's Wi-Fi
  • Mac also joins the travel router's Wi-Fi
  • Mac's Ethernet port connects by cable to the E-Box
With a travel router (like a GL.iNet), leave the Mac's network adapter on "Using DHCP." The router hands out the address, which may not be 2.x.x.x. The static 2.0.0.10 setting below is only for connecting a cable straight from the Mac to the box, with no router.

On the iPad, open Safari and go to the address shown in the DMX Scene Builder window on the Mac, something like http://jeffs-macbook.local:8080 or http://192.168.x.x:8080.

Turn off "client isolation" (sometimes called "AP isolation") on the travel router's settings. If it's on, devices on the router can't see each other, and the iPad won't be able to reach the Mac.

In Safari, tap the share icon and choose "Add to Home Screen." That gives you an icon that opens DMX Scene Builder full screen, like an app.

If the computer has more than one active network connection (Wi-Fi and Ethernet, say), open Setup and pick which one to search on, under "Network adapter." If Find can't reach the box, this is usually why.

Fallback: no network needed

If the network setup is giving trouble, use Sidecar instead: the iPad becomes a second screen for the Mac, over its own cable or Wi-Fi connection to the Mac, with no router involved at all.

Box menu

E-Box settings

Settings only take effect after a power cycle. Turn the box off, then back on, after changing anything below.
  • Personality > DMX Input = Ethernet
  • Personality > Ethernet Settings > Ethernet mode = Artnet
  • Art-Net Settings > Net / Sub-Net / Universe, default is 0 / 0 / 0. Match these numbers in the app.

E-box mode: the Calumma XS modules usually run in Pass-Thr (pass through), where each module has its own DMX address.

Info > IP Addr shows the box's own IP address (factory default starts with 2, and is generated from the box's hardware ID).

REAP (the box's built-in web page)

Open http://<box IP> in a browser. Login is robe / 2479.

  • The Devices screen has a "Discover devices" button that lists the modules plugged in.
  • From there you can change a module's address and DMX preset (mode), and press Start identify to make one module flash.
DMX Hold (holding the last look when data stops) is not available in Pass-Thr mode.
Every float, every day

Daily workflow in the app

  1. Pick the float in the list on the left.
  2. Go to the Patch tab.
  3. Press Find boxes on network, then press Use for E-Box A (or B) on the box that answers.
  4. Press Scan fixtures (RDM).
  5. Scan matches each light to your patch by address. A ✓ in the Light column means the real light matches. Use Identify to flash one.
  6. A light Scan can't match shows under the list: Identify it, then pick which fixture it is.
  7. If addresses clash, press Auto-address, then Send patch addresses to fixtures.
  8. Press Go live on this float.
  9. Go to the Look tab. Tap individual lights, or use All / Tunable white / RGB + White, then set Brightness, Colour temperature, or Colour.
  10. Press Save current look (it's stored on the Mac, per float).
Multi-select: tap as many lights as you like. Every selected light changes together when you set Brightness, Colour temperature, or Colour. Tap a selected light again to drop it from the selection.
After a Scan, each fixture row has a ⋯ button. It shows that fixture's own maker settings (like Terminator active) and lets you change them.
If Scan says the box didn't answer RDM: open REAP, or use Robe Toolkit, to set addresses and modes there instead. Type the same values into the Fixtures table in the app, then use the Address finder to confirm each one. It lights one fixture-sized block of channels at a time, so watch the float and note which light comes on.
Look tab

Saved colors

In the Look tab, select a light and press + Save this color. You can also save its brightness at the same time. Saved colors appear on every float, not just the one you saved it from.

To use one: select any lights first (tap one, tap several, or use All / Tunable white / RGB + White), then tap a saved color to apply it to all of them at once.

RGB colors skip tunable white lights, since they can't show color. White colors work on both RGB and tunable white lights.

Making the float run on its own

Stand-alone save

The Save to fixtures tab has two ways to make a float hold its look with nothing connected. Try option 1 first.

Option 1: Save by RDM

Works in any mode, including tunable white. No Scan needed: it finds every fixture on the box by itself.

  1. Go to the Save to fixtures tab.
  2. With the float live and showing the look you want, press Save look on the Save tab.
  3. The app sets each fixture's own manufacturer setting called Init position LEDs to 1. It finds that setting by name in the fixture's own settings list. This keeps the current look as the fixture's power-on look.
  4. Check it: press Release. If the look holds, you're done.
  5. If it doesn't hold: on the box, set Personality > Output Data to Disabled and power cycle the box, then check again.

Option 2: Save with Mode 7

Only Mode 7 (15 channels) has this save command, and it's documented for the RGB + White fixtures. Steps:

  1. Go to the Save to fixtures tab.
  2. Switch the fixtures to Mode 7 (this re-addresses the box; the status pill shows "Re-addressing, output at zero" while it happens).
  3. Set the look.
  4. Press Save look into fixture(s). This holds the save command for about 5 seconds.
  5. Press Check what's saved. The live look goes dark, and the fixtures show their stored look for 6 seconds.
  6. On the box: Personality > Output Data = Disabled (or the same thing in REAP's Personality screen, then press the red Reset now).
  7. Power cycle the box.
  8. The lights should come up in the saved look, with nothing connected.
To undo: set Output Data back to Enabled and power cycle again.
Never leave a "Special function" value parked partway through. The app handles the timing for you, so just use the button.
Read this before day one

Tunable white warning

Option 1, save by RDM, is the likely path for tunable white fixtures. The Calumma chart only lists Modes 11, 12, and 13 for tunable white, and none of them has a save channel the way Mode 7 does, but the RDM save does not depend on mode.

Day one plan:

  1. Scan a tunable white fixture, then open Patch > Scan > Settings on that fixture and look for "Init position LEDs".
  2. If it's there, use Save look on the Save tab.
  3. If a fixture has no "Init position" setting, the app's Settings list shows whatever it does offer instead. In that case, fall back to: putting a small DMX or Art-Net playback unit on the float to hold the look, or asking Anolis or Robe support how tunable white modules store a power-on look.

Draft question for support, ready to copy and send:

"We have Anolis Calumma tunable-white modules on Anolis E-Box Remote boxes, run in Pass-Thr mode. We need each float to power on showing a fixed look, with no console connected. The DMX chart shows Modes 11/12/13 for tunable white with no 'save to fixture' channel, unlike Mode 7 on the RGBW modules. Is there a way for a tunable-white module to store and recall a look at power-on, and if so, what mode and channel sequence does it need? Specifically, how do we store a power-on look on a tunable-white Calumma module using RDM, and which manufacturer setting controls it?"
Some floats are different

Live DMX floats

A float set to On live DMX input (Patch > Float details) does not run stand-alone. It takes live DMX from show control during the parade. Its last tab is called Parade.

  1. Every Calumma needs its own address.
  2. Pick the mode the show-control programmer wants (Mode 11 = 3 channels per tunable white fixture).
  3. Scan, then check each light with Identify.
  4. Press Auto-address, then Send addresses to fixtures at the bottom of the Fixtures list.
  5. Check the result with Flash or the Address finder.
  6. Print the patch sheet for the programmer.
  7. On the box: leave Output Data Enabled. Set DMX Input to Wired DMX if show control arrives on a DMX cable, or keep it on Ethernet and match Net / Sub-Net / Universe if it arrives over the network.
  8. Power cycle the box.
  9. Press Release.
Any float can be switched between "On its own" and "On live DMX input" in Patch > Float details.
If something isn't working

Troubleshooting

ProblemCheck
Nothing foundThe cable is seated in the box's network port; the computer and box are on the same network (Setup shows the computer's address); the box's DMX Input is set to Ethernet and it's been power-cycled since; the box's IP shown in its Info menu.
More than one network is active (Wi-Fi and Ethernet, or two adapters)Setup > Network adapter: pick the one connected to the box instead of Automatic.

iPad can't load the pageIs it on the same Wi-Fi as the Mac? Is client isolation off on the router? Use the exact address shown in the DMX Scene Builder window. If nothing works, fall back to Sidecar.

Two fixtures do the same thingThey share a DMX address. Use Auto-address then Send patch addresses to fixtures, or fix it directly in REAP.

Data

Where things are saved

Everything lives on the Mac at:

~/Library/Application Support/DMXSceneBuilder/project.json

with a backup made every minute in the backups folder next to it.

Use Setup > Export project to copy a fresh backup to Dropbox.

A new install starts with made-up demo floats. Load your own show with Setup > Import project. Show data stays on the Mac and is never part of the app's code.
